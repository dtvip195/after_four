## 7. Evidence sufficiency and review workflow

| Working label | Meaning |
| --- | --- |
| `NOT_REVIEWED` | No source assessment performed. |
| `SOURCE_IDENTIFIED` | Relevant/controlling source known; completeness not implied. |
| `EVIDENCE_COLLECTED` | Bounded material retained with provenance; sufficiency not implied. |
| `UNDER_REVIEW` | Authority, scope, currency, conflict and limitations being assessed. |

No candidate is initialized as `READY_FOR_OWNER_REVIEW`. Recorded decisions use `SOURCE_IDENTIFIED`; all conditional, unresolved, clarification and blocked rows use `GAP_REMAINS`.
